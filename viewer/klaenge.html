Kampfklänge zum Anhören

Jeder Klang kommt aus der echten Klangmaschine des Spiels (src/audio/sound.ts), so wie er im Kampf erklingt: in jedem Durchgang ein wenig anders, und je weiter weg, desto dumpfer und später. Klick auf ▶, bewerte mit gut, geht so oder schlecht und schreib bei Bedarf dazu, was stört. Unten steht alles als Text zum Kopieren. Die Bewertungen bleiben in diesem Browser gespeichert.

Neu überarbeitete Klänge tragen die Markierung neu, deine vorige Bewertung steht jeweils darunter. Die Klänge mit „im Code vorgerechnet“ entstehen beim Start einmal im Code (src/audio/forge.ts): Rauschen mit fallenden Resonanzen, Bass-Punch, Metallmoden und Nachhall statt einzelner Oszillatoren.

Abstand: Der erste Klick schaltet den Ton ein.
